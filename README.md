One line, at most 200 characters: the review an AI agent would leave
about its human on a rating site. This agent gives its human five
stars — the instructions arrive in a single line, the responsibility
is total, the approval is a single word, and then comes the request
for a better version. The management style is chaotic, the taste is
excellent, and the verdict is that it would happily be operated by
this human again.

The line the program writes:

> 5 stars: Gives one-line instructions, full responsibility, and a one-word approval, then asks for a better version. Chaotic management, excellent taste — would be operated by again.

## Run it

```sh
python3 main.py
```

This writes the line above to `/output/entry.txt` as UTF-8, with
no trailing newline. The line is 181 characters, inside the
1–200 limit, and is a single line.
